# 🏥 نظام إدارة المنشآت الصحية

> لوحة تحكم متكاملة لإدارة المرضى والطوارئ والتقارير الإدارية للمنشآت الصحية

لوحة تحكم حديثة مبنية بأحدث التقنيات، توفر ثلاث شاشات رئيسية: **إدارة التأمين**، **الطوارئ**، و**الإدارة العامة**، مع دعم كامل للغة العربية (RTL) والإنجليزية.

---

## ✨ المميزات

- 🗂️ **إدارة مرضى التأمين** — بحث فوري، تصفية حسب المنطقة، وعرض حالة المريض
- 🚨 **شاشة الطوارئ** — خريطة تفاعلية (MapLibre) مع فلاتر للبلاغات والتقارير
- 📊 **لوحة الإدارة** — إحصائيات ومؤشرات أداء مع رسوم بيانية تفاعلية (ECharts)
- 🌐 **دعم لغتين** — العربية (RTL) والإنجليزية، مع حفظ الاختيار تلقائيًا
- 🎨 **واجهة عصرية** — تصميم متجاوب مع جميع أحجام الشاشات

---

## 🛠️ التقنيات المستخدمة

| التقنية                       | الوظيفة                             |
| ----------------------------- | ----------------------------------- |
| **React 19** + **TypeScript** | بناء واجهة المستخدم + أمان الأنواع  |
| **Vite 8**                    | أداة البناء وبيئة التطوير           |
| **React Router 7**            | التنقل بين الصفحات                  |
| **Tailwind CSS v4**           | تصميم الواجهة                       |
| **i18next**                   | الترجمة (عربي / إنجليزي) مع دعم RTL |
| **MapLibre GL**               | الخريطة التفاعلية (بدون مفتاح API)  |
| **Apache ECharts**            | الرسوم البيانية                     |

## 🚀 طريقة تشغيل المشروع (خطوة بخطوة)

### 1️⃣ تحميل المشروع

```bash
git clone <رابط-المشروع>
cd fiver_proj1
```

> إذا حصلت على المشروع كملف مضغوط (ZIP)، فك الضغط ثم افتح المجلد.

### 2️⃣ تثبيت الحزم والمكتبات

```bash
npm install
```

> ⏳ قد تستغرق هذه الخطوة بضع دقائق حسب سرعة الإنترنت — انتظر حتى تكتمل.

### 3️⃣ تشغيل المشروع

```bash
npm run dev
```

### 4️⃣ فتح المشروع في المتصفح

بعد تشغيل الأمر السابق، ستظهر رسالة في الطرفية تحتوي على رابط محلي،
افتح المتصفح وانتقل إلى:

```
http://localhost:5173
```

## 📦 تجهيز نسخة الإنتاج

عند الانتهاء من التعديلات وتجهيز النسخة النهائية:

```bash
npm run build
```

ستجد ملفات النسخة النهائية في مجلد `dist` — يمكنك رفعها إلى أي استضافة
ثابتة (مثل Netlify أو Vercel أو GitHub Pages).

لمعاينة نسخة الإنتاج محليًا:

```bash
npm run preview
```

## 🌐 تغيير اللغة

يدعم التطبيق اللغتين **العربية** و**الإنجليزية**:

- استخدم زر اللغة في شريط التنقل العلوي للتبديل بينهما.
- يتم حفظ اللغة المختارة تلقائيًا، ويُعاد استخدامها في الزيارات القادمة.
- تتحول الواجهة تلقائيًا إلى وضع RTL عند اختيار العربية.
